Écosystème

Ajouter une bulle

Catégories : cliquer sur un nom pour l'ajouter à la nouvelle bulle, sur le rond pour changer la couleur

Double-cliquez dans l'espace pour créer une bulle. Glissez une bulle pour la déplacer. Pour relier deux bulles, tirez la petite flèche qui apparaît à droite d'une bulle jusqu'à l'autre. Cliquez sur une bulle pour modifier son nom, ses catégories ou sa note, et sur un lien pour lui donner un libellé, l'inverser ou le supprimer. Glissez le fond pour vous déplacer, molette pour zoomer. Pour déplacer ou aligner plusieurs bulles : Maj + clic sur chaque bulle, ou Maj + glisser sur le fond pour les entourer (bouton Sélection pour le faire sans clavier), puis choisissez un alignement dans la barre.
